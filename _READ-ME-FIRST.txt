UPLOAD ALL 7 FILES IN THIS FOLDER. NOTHING ELSE IS NEEDED.

WHY THIS FOLDER EXISTS
  hrmodules.js keeps getting left behind. It is the file that removes the Run payroll
  button and stops your typed additions being lost. Without it, nothing on the payroll
  screen changes no matter how many times you upload the others.

HOW
  1. Open  https://github.com/nakodagrp/-Nakoda-MIS
  2. Add file  ->  Upload files
  3. Open this folder, press Ctrl+A to select ALL files, drag them onto the GitHub page
  4. WAIT until GitHub lists all 7 file names on screen. Do not rush this step.
     If it lists fewer than 7, drag the missing ones again before continuing.
  5. Scroll down, press  Commit changes
  6. Wait 1-2 minutes for GitHub Pages to rebuild

CHECK IT WORKED
  Open  https://nakodagrp.github.io/-Nakoda-MIS/deploy-check.html
  Every row must say NEW in both columns.
  If a row says OLD, that page tells you exactly which of the two problems you have.

THE TELL, ON THE PAYROLL SCREEN
  Before:  a red "Run payroll" button, and "No payslips. Pick a month and Run payroll."
  After:   no button at all, and "No staff to show for this month."

NEVER UPLOAD config.js  - it holds your live /exec URL.
